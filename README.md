# 扫雷 TV

一个为电视遥控器设计的扫雷游戏。横屏布局，棋盘铺满屏幕高度，用不完的宽度做成右侧信息栏；遥控器、鼠标、手柄、触屏都能玩。

![难度](https://img.shields.io/badge/难度-3%20级-yellow) ![minSdk](https://img.shields.io/badge/minSdk-21-blue) ![license](https://img.shields.io/badge/依赖-无-green)

## 界面布局

```
┌───────────┬──────────────────────┬────────────┐
│ 输入调试   │                      │  难度 普通  │
│ (可关闭)   │       扫雷棋盘         │  💣 地雷 10 │
│           │      （铺满高度）       │  ⏱ 02:35  │
│           │                      │  操作提示   │
│           │                      │  本局结果   │
│           │                      │ [新游戏]    │
│           │                      │ [难度]      │
│           │                      │ [排行榜]    │
└───────────┴──────────────────────┴────────────┘
```

- 棋盘始终按格子正方形渲染并居中，高度不够时按高度自适应
- 右侧信息栏占屏宽 26%，文字和按钮都在这里，不挤占棋盘高度
- 左侧是调试面板，默认显示，可用 `INFO` 键切换（见[调试](#调试)）

## 游戏功能

| 功能 | 说明 |
| --- | --- |
| 三种难度 | 普通 9×9 / 10 雷、困难 16×16 / 40 雷、疯狂 20×16 / 60 雷 |
| 首击安全 | 地雷在第一次翻开时才生成，首个格子及其 8 个邻居保证不是雷 |
| 空白扩散 | 翻开空白格自动展开整片连通区域 |
| 插旗标记 | 已插旗的格子不会被翻开，剩余雷数实时显示 |
| 和弦（Chord） | 点已翻开的数字格，当周围旗数等于该数字时，自动翻开其余邻格 |
| 计时 | 第一次翻开开始计时，通关/失败停止；打开难度或排行榜、切到后台时自动暂停，回来继续 |
| 排行榜 | 每种难度各自保存前 10 名（用时 + 日期），SharedPreferences 本地持久化 |
| 结算提示 | 通关/失败弹窗 + 右侧栏长期保留本局结果与名次 |
| 失败揭示 | 踩雷后显示所有地雷，错插的旗子打红叉 |
| 音效 | 翻开/插旗各有一声轻提示音，通关播放上行音阶，失败播放下行音阶（`res/raw` 内自合成的小 WAV，SoundPool 低延迟播放） |

## 操作方式

### 遥控器

| 按键 | 动作 |
| --- | --- |
| 方向键 | 移动光标 |
| 确定 / OK | 翻开（短按）；插旗（长按） |
| 菜单 / 媒体播放暂停 / 彩色键 | 插旗 |
| 方向键 → 在最右列 | 光标跳到右侧按钮区 |
| `INFO` | 切换左侧调试面板 |

### 鼠标

| 操作 | 动作 |
| --- | --- |
| 移动 | 光标跟随，悬停自动聚焦棋盘 |
| 左键 | 翻开（点已翻开的数字 = 和弦） |
| 右键 | 插旗 |

### 手柄

标准 HID 手柄（Xbox One S / Series、PS4/PS5、8BitDo 等）通过蓝牙或 USB 连接即可。

| 按键 | 动作 |
| --- | --- |
| 十字键 / 左摇杆 | 移动光标（按住连续移动） |
| A | 翻开 |
| B / Y / R1 | 插旗 |
| START | 焦点跳到右侧按钮区 |

> 手柄的十字键在 Android 上是摇杆轴事件而非方向键事件，游戏内部会统一处理并把轴方向翻译成焦点导航，所以按钮和弹窗也能用手柄操作。

### 触屏

点击翻开，长按插旗。

## 构建运行

环境要求：

- JDK 17
- Android SDK 35（buildTools 35.0.0）
- 首次构建需要联网下载 Gradle 8.9 与 AGP 8.7.3

```bash
# 组装 Debug APK
./gradlew assembleDebug

# 安装到已连接的电视/盒子
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

技术配置：`compileSdk 35` / `minSdk 21` / `targetSdk 35`，Kotlin 2.0.21，无第三方依赖（仅 `kotlin-stdlib`）。

## 项目结构

```
app/src/main/java/com/example/minesweeper/
├── MainActivity.kt       # 界面组装、计时、弹窗、输入分发
├── BoardView.kt          # 棋盘绘制 + 触屏/鼠标/遥控器/手柄输入
├── MinesweeperGame.kt    # 纯游戏逻辑：布雷、翻开、扩散、和弦、胜负判定
├── Cell.kt               # 单个格子的状态
├── Difficulty.kt         # 三个难度等级
├── LeaderboardStore.kt   # 排行榜持久化
├── GamepadInput.kt       # 手柄轴事件 → 方向解析
├── SoundPlayer.kt        # 音效播放（SoundPool）
└── DebugInputOverlay.kt  # 临时输入调试面板

tools/
└── generate_sfx.py     # 重新生成 res/raw 下的音效文件
```

`MinesweeperGame` 不依赖 Android，可单独测试。

## 调试

左侧调试面板会显示最近按下的按键（`keyCode` / repeat / source / 设备名）、鼠标左右键，以及手柄各轴的原始值和解析出的方向，用来确认某只遥控器或手柄到底发了什么事件。

- 遥控器 `INFO` 键切换显示
- 常量的默认值在 `MainActivity` 的 `SHOW_INPUT_DEBUG`，正式发布前改成 `false`
- 若某个手柄上下方向相反，把 `GamepadInput` 里的 `VERTICAL_SIGN` 改成 `-1f` 即可，棋盘和菜单会一起生效
